
# ReadIt — macOS 화면 바로 번역

**⌥ + 1** (또는 **⌃ + ⌥ + T**)를 누르면 마우스 커서가 위치한 화면을 캡처하여 글자를 인식한 뒤, **원래 글자 자리에 한국어 번역을 덮어서** 표시합니다. 만화·웹소설 등 세로 글줄은 **⌥ + 2**로 세로쓰기 번역을 지원합니다.

모든 처리가 Mac 기기 내 신경망에서 완결되므로(Apple Vision OCR + Apple Translation) **무료이며, API 키가 필요 없고, 인터넷 연결 없이도 오프라인으로 동작합니다.**

## 주요 기능
- **순정 Apple 디자인 & 노치 통합 HUD**: macOS 플로팅 캡슐 HUD와 카메라 하우징 일체형 노치 HUD 중 원하는 스타일 선택 가능.
- **실시간 라이브 번역 (`⌥ + 3`)**: 화면을 백그라운드에서 실시간 캡처·번역하며, 마우스 이벤트가 투과되어 다른 창 작업이나 스크롤을 방해하지 않습니다.
- **구역 지정 번역 (`⌥ + 4`)**: 게임 채팅, 브라우저 본문, 영상 자막 등 원하는 화면 구역만 지정하여 일반 또는 실시간 라이브로 번역합니다.
- **안전한 전역 단축키**: Carbon EventHotKey API를 적용하여 손쉬운 사용(Accessibility) 권한 없이도 안전하게 작동하며, 키보드 프리즈가 전혀 발생하지 않습니다.
- **일본어 세로쓰기 지원**: 세로 글줄을 문맥 단위로 인식하고 자연스럽게 세로 조판(Vertical Layout)으로 번역 표시.
- **언어별 번역 토글**: 자주 쓰는 언어(영어, 일본어 등)만 활성화하여 짧은 영단어가 엉뚱한 언어로 오탐되는 현상을 방지.
- **언어 팩 미설치 하이라이트**: 언어 팩이 없어 번역되지 못한 외국어 텍스트 영역을 붉은색 박스로 명확히 하이라이트.
- **메뉴 막대 제외 옵션**: 화면 상단 메뉴 막대 텍스트(File, Edit 등)를 번역 대상에서 제외하여 본문 내용에만 집중 가능.

## 사용법
| 동작 | 단축키 / 인터랙션 |
|---|---|
| **화면 바로 번역 / 닫기 (토글)** | **`⌥ + 1`** 또는 **`⌃ + ⌥ + T`** |
| **일본어 세로쓰기 번역** | **`⌥ + 2`** (만화/소설 등 세로 글줄 전용) |
| **실시간 라이브 번역 (토글)** | **`⌥ + 3`** (전체 화면 스크롤·작업 중 실시간 자동 번역) |
| **구역 지정 번역 (토글)** | **`⌥ + 4`** (원하는 사각형 구역만 일반/라이브 번역) |
| **닫기** | **`esc`** 또는 **화면 아무 곳이나 클릭** (HUD 닫기 버튼) |
| **원문 잠깐 보기** | **`⌥`** 키 누르고 있기 (또는 HUD의 원문 버튼 클릭) |
| **번역문 전체 복사** | **`⌘ + C`** (또는 HUD의 복사 버튼) |
| **개별 블록 복사** | 번역 문장(블록) 직접 **클릭** (또는 호버 후 **복사 아이콘 클릭**) |
| **언어 팩 / 환경설정** | 메뉴 막대 아이콘 ➔ **`번역 언어 팩 설정…` (`⌘,`)** |
| **업데이트 확인** | 메뉴 막대 아이콘 ➔ **`업데이트 확인…`** (시작 시 자동 확인) |

## 다운로드 및 설치

1. [GitHub Releases](https://github.com/SKR6582/live_caption/releases)에서 최신 `ReadIt.dmg`를 다운로드합니다.
2. DMG를 열고 `ReadIt.app`을 `Applications`(응용 프로그램) 폴더로 드래그하여 설치합니다.

> [!IMPORTANT]
> **최초 1회 보안 경고 해제 안내 ("ReadIt을(를) 열지 않음" / "악성 소프트웨어 확인 불가")**
> Apple Developer 유료 공증이 생략된 오픈소스 빌드이므로, 다운로드 후 최초 실행 시 macOS Gatekeeper 보안 창이 뜹니다.
> **macOS 15 Sequoia 및 macOS 26 Tahoe부터는 우클릭 › 열기만으로는 '열기' 버튼이 나타나지 않으며, 반드시 아래 순서대로 허용해야 합니다.**
>
> **방법 1: 시스템 설정에서 허용 (권장)**
> 1. `Applications`(응용 프로그램) 폴더에서 `ReadIt.app`을 실행합니다.
> 2. `"ReadIt"을(를) 열지 않음` 팝업이 뜨면 **휴지통으로 이동을 누르지 말고 `완료`를 클릭**합니다.
> 3. **시스템 설정** › **개인정보 보호 및 보안**으로 이동한 뒤, 아래쪽 **보안** 섹션으로 스크롤합니다.
> 4. `"ReadIt"이(가) Mac을 보호하기 위해 차단되었습니다` 문구 옆의 **`확인 없이 열기`** 버튼을 클릭합니다.
> 5. 다시 뜨는 확인 팝업에서 **`열기`**를 누르고 Mac 암호(또는 Touch ID)를 입력하면 이후부터 정상 실행됩니다.
>
> **방법 2: 터미널 명령어로 즉시 해제**
> 터미널(Terminal.app)을 열고 아래 명령어를 한 줄 실행하면 보안 경고 없이 바로 열립니다.
> ```bash
> xattr -cr /Applications/ReadIt.app
> ```

> [!IMPORTANT]
> **화면 기록 권한 필수 허용**
> 화면 내 글자를 캡처하여 OCR로 인식하기 위해 화면 기록 권한이 필수입니다.
> - **시스템 설정** › **개인정보 보호 및 보안** › **화면 및 시스템 오디오 기록**에서 `ReadIt`을 허용으로 설정합니다.

> [!TIP]
> - 번역된 문장 블록을 마우스로 클릭하면 해당 번역문이 클립보드로 즉시 복사됩니다.
> - 번역 오버레이 상태에서 `⌥` 키를 누르고 있으면 원본 화면을 일시적으로 확인할 수 있습니다.
> - 자주 쓰지 않는 외국어는 메뉴 막대 아이콘의 설정(`⌘,`)에서 비활성화하여 오탐을 방지할 수 있습니다.

## 요구 사항
- **macOS 15.0 (Sequoia) 이상** 및 **macOS 26.0 (Tahoe) 이상** 호환
- Apple Silicon (M1/M2/M3/M4) 또는 Intel Mac (Universal Binary)

## 소스코드 빌드
```bash
# 기본 Swift 빌드
swift build -c release

# 앱 번들 생성 및 실행
./build.sh          # build/ReadIt (Test).app 생성 (테스트용, 권한 분리)
./build.sh run      # 테스트용 빌드 후 바로 실행
./build.sh release  # build/ReadIt.app 생성 (정식 배포용)
./build.sh install  # /Applications 에 설치 후 실행 (정식 배포용)
./build.sh dmg      # build/ReadIt.dmg 파일 생성 (정식 배포용)
```
