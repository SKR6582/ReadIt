
# ReadIt — macOS 화면 바로 번역

**⌥ + 1** (또는 **⌃ + ⌥ + T**)를 누르면 마우스 커서가 위치한 화면을 캡처하여 글자를 인식한 뒤, **원래 글자 자리에 한국어 번역을 덮어서** 표시합니다. 만화·웹소설 등 세로 글줄은 **⌥ + 2**로 세로쓰기 번역을 지원합니다.

모든 처리가 Mac 기기 내 신경망에서 완결되므로(Apple Vision OCR + Apple Translation) **무료이며, API 키가 필요 없고, 인터넷 연결 없이도 오프라인으로 동작합니다.**

## 주요 기능
- **순정 Apple 디자인 & 노치 통합 HUD**: macOS 플로팅 캡슐 HUD와 카메라 하우징 일체형 노치 HUD 중 원하는 스타일 선택 가능.
- **실시간 라이브 번역 (`⌥ + 3`)**: 화면을 백그라운드에서 실시간 캡처·번역하며, 마우스 이벤트가 투과되어 다른 창 작업이나 스크롤을 방해하지 않습니다.
- **구역 지정 번역 (`⌥ + 4`) & 프리셋**:
  - **마지막 구역 자동 복원**: `⌥ + 4`를 누르면 매번 드래그할 필요 없이 직전에 사용한 구역과 모드(일반/라이브/세로)를 즉시 복원합니다.
  - **이름 있는 프리셋 (최대 5개)**: 게임 채팅, 브라우저 본문, 자막, 만화·소설 등 자주 쓰는 구역을 저장해 HUD와 상단 메뉴 막대에서 한 번에 꺼내 쓸 수 있습니다.
  - **드래그 이동 및 모서리 크기 조절**: 구역 테두리를 드래그해 위치를 옮기거나 8방향(모서리·변) 핸들을 드래그해 크기를 즉시 조절할 수 있습니다.
  - **구역 내 세로쓰기 통합**: 구역 컨트롤의 `세로` 토글을 켜면 창 안에서 스크롤되는 만화·웹소설 세로 글줄을 실시간으로 번역합니다.
- **안전한 전역 단축키**: Carbon EventHotKey API를 적용하여 손쉬운 사용(Accessibility) 권한 없이도 안전하게 작동하며, 키보드 프리즈가 전혀 발생하지 않습니다.
- **언어별 번역 토글 & 미설치 하이라이트**: 자주 쓰는 언어만 활성화하여 오탐을 방지하고, 언어 팩이 없는 텍스트는 붉은색 박스로 안내합니다.
- **영구 번역 캐시 & 최근 복사 내역**: 이미 번역한 문장을 디스크에 캐시하여 재번역 지연을 줄이고, 최근 복사한 문장을 HUD에서 다시 복사할 수 있습니다.

## 사용법
| 동작 | 단축키 / 인터랙션 |
|---|---|
| **화면 바로 번역 / 닫기 (토글)** | **`⌥ + 1`** 또는 **`⌃ + ⌥ + T`** |
| **일본어 세로쓰기 번역** | **`⌥ + 2`** (전체 화면 세로 글줄 전용) |
| **실시간 라이브 번역 (토글)** | **`⌥ + 3`** (전체 화면 스크롤·작업 중 실시간 자동 번역) |
| **구역 지정 번역 (토글)** | **`⌥ + 4`** (직전 구역 즉시 복원 / 최초 실행 시 드래그 지정) |
| **구역 이동 / 크기 조절** | 구역 **테두리 드래그(이동)** / **모서리·변 핸들 드래그(크기 조절)** |
| **구역 프리셋 전환 / 저장** | 상단 HUD **`프리셋`** 버튼 또는 메뉴 막대 아이콘에서 선택 |
| **닫기** | **`esc`** 또는 HUD 닫기 버튼 |
| **원문 잠깐 보기** | **`⌥`** 키 누르고 있기 (또는 HUD의 원문 버튼 클릭) |
| **번역문 전체 복사** | **`⌘ + C`** (또는 HUD의 복사 버튼) |
| **개별 블록 복사** | 번역 문장(블록) 직접 **클릭** |
| **언어 팩 / 환경설정** | 메뉴 막대 아이콘 ➔ **`번역 언어 팩 설정…` (`⌘,`)** |
| **업데이트 확인** | 메뉴 막대 아이콘 ➔ **`업데이트 확인…`** (시작 시 자동 확인) |

## 다운로드 및 설치 (보안 경고 해제 상세 가이드)

1. [GitHub Releases](https://github.com/SKR6582/ReadIt/releases)에서 최신 **`ReadIt.dmg`**를 다운로드합니다.
2. 다운로드한 `ReadIt.dmg`를 더블 클릭해 열고, **`ReadIt.app` 아이콘을 `Applications`(응용 프로그램) 폴더로 드래그**하여 복사합니다.

> [!IMPORTANT]
> ### 최초 실행 시 보안 경고("ReadIt을(를) 열지 않음") 해결 방법
> 이 앱은 유료 Apple Developer 공증(Notarization) 없이 배포되는 오픈소스 앱이므로, 인터넷에서 다운로드한 직후 실행하면 macOS Gatekeeper가 실행을 한 번 차단합니다.
> **특히 macOS 15 Sequoia 및 macOS 26 Tahoe부터는 Finder에서 `우클릭 › 열기`를 눌러도 곧바로 '열기' 버튼이 나오지 않고 차단 창만 뜨므로, 반드시 아래 방법 1 또는 방법 2를 따라야 합니다.**
>
> ---
>
> #### 방법 1: 시스템 설정에서 허용하기 (일반 사용자 권장)
>
> | 단계 | 화면에서 해야 할 동작 | 주의 사항 |
> | :--- | :--- | :--- |
> | **1단계** | `Applications`(응용 프로그램) 폴더에서 **`ReadIt`**을 더블 클릭해 실행합니다. | DMG 창 안이 아니라 복사된 **응용 프로그램 폴더**에서 실행하세요. |
> | **2단계** | `"ReadIt"을(를) 열지 않음 — Apple에서 악성 소프트웨어가 있는지 확인할 수 없습니다` 팝업이 뜨면 **`완료`** 버튼을 클릭합니다. | **`휴지통으로 이동`을 누르면 앱이 삭제됩니다. 반드시 `완료`를 누르세요.** |
> | **3단계** | Mac 좌측 상단 `` 메뉴 › **`시스템 설정(System Settings)`**을 엽니다. | |
> | **4단계** | 왼쪽 사이드바에서 **`개인정보 보호 및 보안(Privacy & Security)`**을 클릭한 뒤, **맨 아래쪽 `보안(Security)` 섹션**까지 스크롤합니다. | 2단계에서 `완료`를 누른 직후에만 이 항목이 표시됩니다. |
> | **5단계** | `"ReadIt"이(가) Mac을 보호하기 위해 차단되었습니다` 문구 오른쪽의 **`확인 없이 열기(Open Anyway)`** 버튼을 클릭합니다. | |
> | **6단계** | 다시 확인 팝업이 뜨면 **`열기(Open)`** 버튼을 누르고 **Mac 로그인 암호 입력 또는 Touch ID**로 승인합니다. | 최초 1회만 승인하면 이후에는 경고 없이 바로 실행됩니다. |
>
> ---
>
> #### 방법 2: 터미널 명령어로 한 번에 해제하기 (가장 빠름, 손상 경고 해결 포함)
> 만약 위 과정이 번거롭거나 `"ReadIt"이(가) 손상되었기 때문에 열 수 없습니다`라는 메시지가 뜬다면, 다운로드 시 부여된 격리 속성(`com.apple.quarantine`)만 제거하면 즉시 실행됩니다.
>
> 1. `Spotlight`(`⌘ + Space`)에서 **`터미널`**(`Terminal`)을 검색해 실행합니다.
> 2. 아래 명령어를 복사해 붙여넣고 `Enter`(Return)를 누릅니다.
>    ```bash
>    xattr -cr /Applications/ReadIt.app
>    ```
> 3. 이제 `Applications` 폴더의 `ReadIt`을 실행하면 보안 경고 없이 즉시 켜집니다.

> [!IMPORTANT]
> ### 화면 기록 권한 허용 (필수)
> 화면의 외국어 글자를 캡처해 OCR로 읽기 위해 **화면 기록 권한**이 필요합니다.
> 1. 첫 실행 시 권한 안내가 뜨면 **`시스템 설정 열기`**를 클릭합니다 (또는 **시스템 설정 › 개인정보 보호 및 보안 › 화면 및 시스템 오디오 기록** 이동).
> 2. 목록에서 **`ReadIt`** 스위치를 **켬(ON)**으로 바꿉니다 (목록에 없다면 아래 `+` 버튼으로 `/Applications/ReadIt.app` 추가).
> 3. 이미 켜져 있는데도 권한 경고가 뜬다면(업데이트 직후 등), `ReadIt` 항목을 선택한 뒤 아래 `-` 버튼으로 지웠다가 다시 `+` 버튼으로 `/Applications/ReadIt.app`을 등록해 주세요.

> [!TIP]
> - 번역된 문장 블록을 마우스로 클릭하면 해당 번역문이 클립보드로 즉시 복사됩니다.
> - 번역 오버레이 상태에서 `⌥` 키를 누르고 있으면 원본 화면을 일시적으로 확인할 수 있습니다.
> - 자주 쓰지 않는 외국어는 메뉴 막대 아이콘의 설정(`⌘,`)에서 비활성화하여 오탐을 방지할 수 있습니다.

## 요구 사항
- **macOS 15.0 (Sequoia) 이상** 및 **macOS 26.0 (Tahoe) 이상** 호환
- Apple Silicon (M1/M2/M3/M4) 또는 Intel Mac (Universal Binary)

## 소스코드 빌드
```bash
# 기본 Swift 빌드
swift build -c release

# 앱 번들 생성 및 실행
./build.sh          # build/ReadIt (Test).app 생성 (테스트용, 권한 분리)
./build.sh run      # 테스트용 빌드 후 바로 실행
./build.sh release  # build/ReadIt.app 생성 (정식 배포용)
./build.sh install  # /Applications 에 설치 후 실행 (정식 배포용)
./build.sh dmg      # build/ReadIt.dmg 파일 생성 (정식 배포용)
```
